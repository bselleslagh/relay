# App screenshots

These are unedited iPhone Simulator captures from the public app configuration, taken during the passing UI test suite. All three screens run with `--demo`, display the sample-data banner and use synthetic counts. Demo mode does not access HealthKit, pair with a server, persist settings or send uploads.

- `sync.png`: upload status and the animated pixel athlete.
- `data.png`: supported health-data groups.
- `settings.png`: connection, sync and Apple Health controls.

No personal account, server address, credential or real health record is included. Original device screenshots, recordings and test-result manifests are excluded from the repository.
